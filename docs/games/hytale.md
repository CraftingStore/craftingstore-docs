# Hytale

We have a plugin that supports the official Hytale server! It has all the features that you need, from realtime command processing to only running commands for online players.

### How to Install the plugin?
The installation will be like any other plugin/mod that you already have, just drop our CraftingStore.jar plugin into your mods folder.

1. Download the CraftingStore plugin, you can find it at the "Servers" section in the right top corner.
2. Upload the CraftingStore.jar into the mods folder, like any other mod.
3. Restart your server.
4. The plugin now created a config (mods/CraftingStore_CraftingStore/config.json) - You do not need to touch this.
5. Go to your console and execute `craftingstore key keyfromdashboard`
